# nunui

nunui is Material 3 based lightweight Svelte 5 UI components library.

## Install

```sh
pnpm add nunui
```

## Use

```ts
import 'nunui/base.css';
import { ThemeProvider, Button } from 'nunui';
```

The full docs site lives in the workspace `packages/docs` app and is published as the GitHub Pages site for this repository.
